# テスト（tests/）

## 単体テスト（tests/unit/）

`npm test` で全部まとめて動きます（Vitest）。どれも画面や Neon・Render を使わない、関数1つずつのテストです。

| ファイル | 確かめること |
|---|---|
| `checkPassword.test.ts` | パスワードの条件（8〜16文字・英字と数字の両方） |
| `wouldCycle.test.ts` | 前提項目が輪にならないか |
| `split.test.ts` | AIに送る内容を1万文字ごとに分ける・利用回数の数え方 |
| `gradeMeaningToTerm.test.ts` | 「意味→用語」の採点（全角半角・大文字小文字・前後の空白） |
| `words.test.ts` | 単語枠の「用語：意味」の分け方（前に「12:30」が「1230」になったバグの再発防止） |
| `logic.test.ts` | 校正の「元→先」の置き換え・ファイル名がかぶらないこと・問題数（5〜20問）・新しい部品の大きさと位置 |
| `select.test.ts` | 科目や学習項目のIDで探す関数（ほかのものがまざらない・並び順・見つからなくても落ちない）と、テスト一覧に出す前回の点数 |
| `shape.test.ts` | 図形の形（四角・丸）の読み方と変え方 |
| `history.test.ts` | ノートの「元に戻す」「やり直す」（続けての変更は1回分にまとめる・順番・上限） |
| `searchTree.test.ts` | 左の一覧の検索（科目名・学習項目名、全角半角・大文字小文字） |
| `deleteTests.test.ts` | テストの削除（1つ・まとめて・何も選んでいない・ないテストがまざっていたら消さない） |
| `sortTests.test.ts` | テスト一覧の並べかえ（作った日・最近解いた・点数が低い・名前。未受験や点数のないものは後ろ） |
| `ymd.test.ts` | テスト名に使う日付（8けた・1けたの月日に0を付ける） |
| `canvasWidth.test.ts` | ノートに要る幅（全画面で右に置いた部品が、ふつうの画面で切れないように） |
| `nodeLabel.test.ts` | 関連図の丸の中の名前（4文字ずつ2行まで、入らない分は「…」） |
| `isPullStale.test.ts` | ページを開き直したときに受け取り直すか（30分以内なら受け取らない・時刻が読めない／未来なら念のため受け取る） |
| `nameError.test.ts` | 科目名・学習項目名の確認（空・空白だけはだめ・50文字まで・絵文字も1文字と数える） |

初めて動かすときは、先に `npm install` をしてください（Vitest が入ります）。
テストのファイルは `src/` の外にあるので、`npm run build` には影響しません。
