# テスト（tests/）

## 単体テスト（tests/unit/）

`npm test` で全部まとめて動きます（Vitest）。どれも画面や Neon・Render を使わない、関数1つずつのテストです。

| `links.test.ts` | 学習項目のつながり（一周しないか・足す線と消す線・名前の順） |
| `linkCycleRegression.test.ts` | 前提関係の循環検出に関する回帰テスト（正常な接続・自己参照・循環の検出・循環の解消） |
| `split.test.ts` | AIに送る内容を1万文字ごとに分ける・利用回数の数え方 |
| `gradeMeaningToTerm.test.ts` | 「意味→用語」の採点（全角半角・大文字小文字・前後の空白） |
| `words.test.ts` | 単語枠の「用語：意味」の分け方（前に「12:30」が「1230」になったバグの再発防止） |

初めて動かすときは、先に `npm install` をしてください（Vitest が入ります）。
テストのファイルは `src/` の外にあるので、`npm run build` には影響しません。

## CI（継続的インテグレーション）

GitHub Actions（`.github/workflows/ci.yml`）によって、
以下の品質検査を自動実行する。

- フロントエンド・バックエンドの依存関係のインストール
- TypeScript型チェック
- 全単体テスト
- 本番ビルド
- バックエンドのJavaScript構文チェック
- フロントエンド・バックエンドの依存パッケージ脆弱性検査

対象ブランチへのpush、およびmain・pm/stabilizationへの
プルリクエストを契機として実行する。

検査に失敗した場合は原因を修正し、再検証すること。

CIでは実際のNeonや外部AIサービスには接続しない。
実環境での結合試験・総合試験は別途実施する。
